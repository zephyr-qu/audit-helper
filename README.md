# 合规审查助手

浏览器扩展。在招聘审核后台自动高亮违规关键词，按处置档位给出审核结论，辅助审核员快速识别合规风险。

仅做页面本地自查提示，不调用任何平台接口，也不拦截或代替审核操作。

## 功能

- **关键词审查**：扫描页面可见文本，命中词库即高亮，支持按档位过滤、上一条/下一条定位、点击命中项跳转。
- **处置档位**：档位对应 6 种处置动作（建议驳回 / 退回修改 / 人工核实 / 补充资质 / 教育警示 / 仅作提示）；6 种动作归入 **3 种行为级别**（阻断 / 待核实 / 提示），由级别决定结论、角标与排序；最终结论另有「未发现风险」与「信息不足」两种兜底态。档位顺序由处置动作决定，不需要手动调整。
- **内置规则包**：依据《BOSS直聘招聘行为管理规范》(2023-12 版) 整理的分组，带条款依据与处理建议。
- **审核意见**：一键复制带依据、建议、命中次数的完整意见文本。
- **扩展角标**：按 tab 汇总「建议驳回」档位的命中数（跨 iframe）。
- **右键加词**：选中文本右键即可加入指定分组。
- **按钮提示**：点击「发布 / 驳回」类按钮时浮出命中清单，只提示不拦截。

## 安装与使用

1. 打开 `chrome://extensions`，开启「开发者模式」。
2. 点「加载已解压的扩展程序」，选择扩展的构建目录。
3. 打开目标审核页面即可生效。

## 关键设置

| 设置 | 说明 |
|---|---|
| 扫描模式 | `实时` 会监听页面变化增量扫描；`仅手动` 只在点「重扫」时扫描 |
| 视口懒扫描 | 只扫当前可见区，滚动到时再扫其余，适合超长页面 |
| 忽略隐藏内容 | 默认开启。`display:none` / `visibility:hidden` 容器里的命中不计入结果，与浏览器页内查找的口径一致 |
| 中文整词 | 按分词判断独立成词，避免「专家教你」跨词拼出「家教」 |
| 英文整词 | 默认关闭。开启后按分词判断英文/数字词是否独立成词，避免「spa」命中「spaces」、「996」命中「1996」 |
| 生效范围 | 全部站点 / 仅指定站点 / 除以下站点外，支持 `*.example.com` |

## 已知限制

- 只审查**渲染出来的文本节点**。属性值（`placeholder`、`title`、`alt`）、表单控件的 `value`、Shadow DOM、canvas/视频内容都不覆盖。
- 隐藏内容默认忽略（可在设置里关闭）。命中若全部位于隐藏区，结论为「可见内容未发现风险项」，并标注未计入的数量。
- 页内面板与 popup 只统计**顶层 frame**，扩展角标则跨 iframe 汇总；两者口径不同，面板与弹窗会额外提示「iframe 内另有 N 处」。
- 高亮会直接改写页面 DOM（插入 `span`）。
